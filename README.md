# ETF 观察台

面向 A 股和境内股票 ETF 的个人研究工具。React 19 + TypeScript 前端、Python 3.12 标准库后端，支持日内行情、日 K、季度持仓、数据覆盖检查，以及带买卖点的逐日策略回放。

## 买卖提醒

研究页现在只展示今日买入观察、模拟卖出与止损参考，以及关注清单。模型选择、规则试验、收益对照等过程信息保留在代码和内部工具，不进入主界面。点ETF本页查看，返回保留筛选、搜索、滚动与焦点。

现有报价约20秒检查一次。盘中买入观察使用六个连续、已经结束的报价采样分钟，结合自身转强和此前已知的位置/风险条件；它与收盘确认的日线B/S分开显示，不代表成交或收益承诺。没有有效新提醒时显示空态，缺失/过期报价不高亮。模拟持仓的止盈、卖出和止损参考在清单与行情页一起显示。详细数据时间口径见 [API](docs/API.md)。

## 已实现

- 关注清单按重点关注、模拟持有、等待买点、数据待更新和全部五类筛选。
- 点 ETF 名称在研究页内查看报价、K 线和前十大持仓；返回清单保留筛选、搜索、滚动和焦点。
- 日线显示 MA5 / MA10 / MA30；默认研究模型v4使用自身MA5/10转强及MA10/ATR位置条件，旧v3的MA20/60逻辑在对照模式原样保留。
- 全部ETF的覆盖、零笔/多笔和开盘取消统计保留为内部分析，不在前台展示。前台聚焦方向清单、逐只行情、当前研究模型B/S及可选旧v3对照。
- 今年日 K 显示 B/S 收盘确认点或 B开/S开模拟执行点，可拖动交易日游标和播放历史回放。未来价格及均线留白，不参与过去的决定。
- v4退出包含结构失效、达到1R后的利润保护、1.5R阶段目标、两日低于MA10、5日无延续及10日复核。日线确认后下一交易日开盘仅作模拟参考，开盘超出此前风险边界取消开仓。
- 每只 ETF 的季度股票前十持仓及修订版本独立保存；后台每日检查当前年和上一年，失败退避重试。
- 自动核对年内日线日期、历史暖机、缺口及复权冲突；上交所清算后份额与全篮子估算流量分开记录。
- 日K可选择近3年；后台每日增量检查日成交额与源换手率，每周复核三年完整区间。价格与量能分开存储，保留修订，不用最新份额反推历史换手。
- 三年上涨阶段与量价研究保留为后台分析，不在研究页或行情页展示；日K仍可选择近3年。前台保持关注清单、按所选模型计算的B/S和退出条件，均为研究模拟。

## 本地运行

需要 Python 3.12+、Node.js 24+ 和 npm。后端不依赖第三方 Python 包。

```sh
cd server
python3 -c "import getpass; from etfmon import auth; auth.set_password('researcher', getpass.getpass('Local password: '))"
python3 -m etfmon serve --host 127.0.0.1 --port 8765
```

默认本地认证；上面的命令会交互式设置本地用户 researcher 的密码，登录时使用该账号。真实行情采集依赖可访问的公开数据源，首次补取需要时间。数据写入 `server/data/`，也可通过 `ETF_DATA` 指定目录。

另开终端：

```sh
cd web
npm ci
npm run dev
```

访问前端开发服务器打印的本机地址。Vite 将 `/api` 代理到本机后端。前端页面可见时自动更新；持续采集需让后端进程保持运行。

# 在仓库根目录；测试使用独立临时目录，不读取真实账户

## 研究口径

- 默认独立模型v4：MA5/10首次转强、MA10位置和ATR风险；旧v3仅作对照。所有模型均无宽基准入条件；准备观察不是完整买点。
- 回放年初空仓、单标的单仓位，成本为0/10/20/40基点往返假设。当前前复权数据和当前基金池存在偏差；模型损益不是实际账户收益，也未经样本外验证。
- 境内股票ETF按T+1约束模拟，不做当日卖出。跨境、黄金等品种不直接套用该模型。参见[深交所交易指南](https://investor.szse.cn/warning/activities/fundIntroduction/t20210104_584079.html)。
- 止损采用收盘确认，次日开盘参考；不模拟盘中成交、涨跌停排队、停牌、最低佣金或实际账户持仓。没有交易账户连接与自动下单。
- 持仓为季度披露，报告期、实际披露日期与采集时间分开；未知日期保持空值。来源不是实时持仓。
- 免费公开行情接口没有实时性SLA，使用者须核对来源与授权范围。历史重算不等于当时实发记录。

数据适配器位于 `server/etfmon/sources.py`、`holdings.py`、`share_history.py`；策略与回放位于 `research.py`、`replay.py`。图表使用 [TradingView Lightweight Charts](https://github.com/tradingview/lightweight-charts)，组件使用 [Meta Astryx](https://github.com/meta/astryx)，依赖遵循各自许可证。

三年量能与覆盖维护位于 `history.py`，描述研究位于 `rallies.py`。如需在本地复算（只读现有数据，不发起行情请求）：

```sh
ETF_DATA=/path/to/data python3 scripts/analyze_three_years.py --out /path/to/analysis
```

输出字段级覆盖、阶段和对照CSV及JSON。详细定义见 [API口径](docs/API.md)。

需要自托管时可将构建后的静态文件放在受保护的反向代理后，后端保持回环监听。`ETF_AUTH_MODE=forward` 仅用于可信反代注入身份的已有认证部署，不能直接公开服务。

### v2.10 独立判断

研究、当年买卖点回放、事件统计和热点排序均只依赖该ETF自身走势。热度原相对沪深300的40分改为自身20日动量40分；旧排名变化不跨版本比较。日线图保留MA5/10/30；入场MA20/60、ATR位置与风险约束、次日开盘超界取消、全部退出规则保持原版。历史B/S为新版本重算，不等于当年实发信号，旧实发记录保留原版本不覆盖。单个ETF的数据过期只暂停自身新判断。交易日缺口仍由后台数据质量维护检查，不以其他指数的价格或强弱阻拦交易路径。

全部ETF买卖点覆盖和三年上涨阶段复盘为内部分析，不出现在研究页或行情页。行情指数和国家队基金份额监测独立保留，不能反向影响其他ETF的信号。

### v2.11 主研究模型替换

默认研究与当年B/S改为 `self-early-turn-v4/protected-bite-v2`：MA5首次上穿MA10、MA10向上，距MA10最多1.5ATR、初始风险最多2ATR；准备失效即重置，无永久consumed标记。收盘确认、次日开盘重查位置/风险。按开盘参考价定义R；达到1R后启用名义开仓价/2ATR利润保护、1.5R阶段目标、两日低于MA10、5日无延续、最多10日复核，均确认后次日开盘参考。没有盘中保证止损或保本。MA30为自身背景，仍不关联任何宽基。

旧v3在回放模型选择中原样保留（含当时的状态逻辑），用于同日期比较；历史实发记录保持原版本，不回填。新旧切换及加载不会混用B/S，拖动日期时先裁剪价格与清空待算标记。

当前62方向历史对照中，v4相对旧版改善典型交易损失与模型回撤，但单笔中位结果仍为负，均值受少数交易日贡献，2026数据已被研究过，不能视为成熟盈利策略。宽松转强/叠加回踩版本因更高回撤与噪音未启用。内部统计保留内部，不增加复盘面板。

### v2.11.1 买卖点显示说明

浏览器记住所选模型、旧版路径、标记类型与成本假设，刷新不再重置模型。图旁区分无合格确认、确认后取消/待开盘、标记在区间外、已隐藏、非日K及读取失败，并提供对应操作。模型切换仍清空不匹配结果；不会自动切换旧版来补画买卖点。策略计算、原始数据与历史记录不变。

显示逻辑验证：`npm --prefix web run test:replay-display`。

### v2.12 扩展机会研究模式

研究页和逐只日K可切换“扩展机会 v5”：自身MA5首次上穿MA10后，包含交叉当天共5个交易日内等待首次合格确认；确认时MA10向上、收盘在MA10上。收盘与下一开盘距此前MA10上限为2ATR，初始结构风险上限为3ATR。失去自身5/10排列即失效，窗口到期不续期，同一窗口仅确认一次。退出仍使用原来的1R保护、1.5R目标和时间/MA10规则。本轮没有启用额外回踩路径或MA30准入条件。

这是按用户风险偏好扩展观察范围的假设，不是回测胜出版本。已观察历史的交易损失、单ETF回撤和退出回吐均可能高于v4；不据交易次数或上涨段覆盖宣称盈利。接口默认仍为v4作兼容对照，页面记住所选模式；v4/v3原有回放和历史档案保留。扩展模式的日终观察以独立v5版本追加，仅记录实际采集当日，不补造历史实发信号。后台刷新及图表买卖点均使用所选模型，加载期间不混用结果。

回放坚持完整收盘确认、下一可用交易日开盘作模拟参考，与[Backtrader订单执行口径](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/)一致；较宽ATR阈值不等于承诺的最大账户亏损。研究页不展示内部三年复盘和全ETF覆盖面板。

### v2.13 单笔7%回撤保护研究

扩展v5可开启“单笔回撤7%保护（日线近似）”。定义为买入后已知最高价回撤7%，每笔持仓独立重置，退出后不禁止未来新结构入场。历史日线采用前一完整交易日已知最高价×93%作为当天保护线；买入当天T+1锁定。此后若开盘跳空低于保护线，按源开盘价参考；否则当日低点触线以保护线作日线假设参考，标记为`S触`，不冒充收盘确认或已证实成交。当前日新高只收紧下一交易日的线；当日新高和低点顺序未知的日期保留在响应中，不补造路径。

原有结构、1R保护、1.5R目标及MA10/时间退出仍有效。开关关闭时原v5/v4/v3行为保留；保护版以独立规则版本与缓存计算，之后实际日终记录追加到独立版本，不补造历史实发信号。研究清单与单只日K共用开关，浏览器记住选择。该项只提供历史研究，未接自动下单；7%是触发阈值，T+1、跳空、成本和连续多笔亏损会使单笔亏损及累计模型回撤超过7%。旧时期结果没有一致改善，尚未形成样本外优势。

执行假设参考[Backtrader止损回放文档](https://www.backtrader.com/docu/order-creation-execution/order-creation-execution/#stop)，股票ETF的T+1见[上交所ETF常见问题](https://www.sse.com.cn/assortment/fund/etf/question/)。前复权日线不能验证逐笔成交、报价跳价、排队或同日高低顺序；实时移动止损还需分钟/逐笔数据另行核实。
