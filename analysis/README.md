# 研究工具

这个目录只放**能重跑的研究脚本**，不放回测结果、不放到期文档、不放页面快照。

生产代码在 `server/etfmon/` 与 `web/src/`。这里的东西不参与部署。

## 文件

| 文件 | 作用 |
|---|---|
| `strategy_lab.py` | 把多个候选策略放在同一套数据、同一套成本假设下测量。输出 JSON。 |
| `strategies_web.py` | 四个公开策略的实现：网格、风险平价、R² 动量、目标权重+趋势过滤。 |

## 怎么跑

这两个脚本要在**有真实数据的机器**上跑（读 `ETF_DATA`），本地开发机通常没有数据。

```sh
# 拷到数据所在机器
scp analysis/*.py <host>:/tmp/

# 在那边执行
ssh <host> 'cd /opt/etf-monitor && ETF_DATA=/opt/etf-monitor/data \
  PYTHONPATH=/opt/etf-monitor python3 /tmp/strategy_lab.py --out /tmp/results.json'
```

输出是一个 JSON 文件，含每个策略的年化、最大回撤、Calmar、分年度、不同起点的稳健性。

## 两个筛选标准

看结果时只信这两条：

1. **分年度** —— 是不是每年都能活。只有某一年特别猛、其他年份平庸甚至亏钱的，本质是在赌行情。
2. **不同起点的年化** —— 起点换成 2016 / 2018 / 2019 / 2021 各算一次。稳的才是真信号；换个起点就掉到个位数的，是运气。

Calmar（年化 ÷ 最大回撤）只能做粗筛。它会把交易次数极少、样本很薄的方案排到前面。

## 踩过的数据坑（都在代码里处理了，但看结果时要记得）

- **单日跌幅超过 25% 的缺口**：A 股 ETF 几乎都是未复权的除权跳空，不是真实下跌。把这种日子当暴跌喂进回测，会跑出年化 1708% 这种荒唐数字。
- **某只标的数据缺失最后几天**：多标的组合若把缺失日当作 0 计入，净值会凭空腰斩（实测出现过 2026-11-12 单日 -49.4%）。现在按最后已知价格前向填充。
- **年化不能用样本点数折算**：月度曲线只有约 94 个点，按交易日折算会把年化放大十倍。必须用日历跨度。
- **把 93 个子账户的曲线平均**：会让空仓期稀释掉所有回撤，得出「回撤 -1%」这种无意义的结论。现在用真实组合回放（共享现金、仓位上限）。
- **基金场外净值不含分红**：`单位净值` 和 `累计净值` 能差 35 个百分点。算收益必须用累计净值。

## 局限

- 回测成本只含 20 基点往返，不含冲击成本、涨跌停、停牌、流动性约束。
- 参数在同一段历史上挑选，天然偏乐观。没有做完整的样本外验证。
- 国家队份额只有 208 个交易日（2026 年），相关结论只能算探索。
- 公开组合（永久、全天候、黄金蝶）在 A 股的年化是 6-7%，不是美股那种数字。别照搬海外的预期。
